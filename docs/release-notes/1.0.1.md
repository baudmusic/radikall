# Radikall 1.0.1

## 简体中文

虽然只是 1.0.0 到 1.0.1，但这是一次从界面到底层都重新装修过的大更新。

- 全国电台总表与全局搜索：不用切换地区，任何电台点一下就能听
- 电台卡片显示正在播出的节目名称、封面和主持人
- 以日本传统色重新设计浅色与深色主题
- 修复安卓端停止播放一段时间后再点播放会闪退的问题
- 断网后自动重连，网络恢复几秒内继续播放

### 更多改进

- 切换浏览地区不再打断正在播放的电台
- 正在播放页列出电台的可收听地区，点一下即可切换过去
- 台名和节目名里的全角英文、数字统一显示为半角（如「ＨＢＣラジオ」→「HBCラジオ」）
- 锁屏挂机收听更稳定，不再因为省电断网而自己停下
- 新增更新提醒：以后有新版本时，App 内会提示下载
- 网页版：禁用下拉刷新，往回划列表、收起播放页时不再误触

### 下载

- Android：`Radikall-release-1.0.1.apk`，可直接覆盖安装 1.0.0，设置会保留
- Windows：`Radikall-Setup-1.0.1.exe`（需先安装 VLC 媒体播放器）
- iOS / macOS：用 Safari 打开 https://radikall-web.baudmusic.workers.dev

## English

It's only 1.0.0 to 1.0.1 on paper, but this update rebuilds almost everything, from the UI down to the networking layer.

- Nationwide station list and global search: play any station in one tap, no area switching
- Station cards show the program on air, with cover art and hosts
- Light and dark themes redesigned with traditional Japanese colors
- Fixed a crash on Android when pressing play after playback had stopped for a while
- Playback reconnects on its own after a network drop and resumes within seconds

### More improvements

- Switching the area you're browsing no longer interrupts the station that's playing
- The now-playing page lists every area where the station is available; tap one to jump there
- Full-width letters and digits in station and program names now display as half-width (e.g. 「ＨＢＣラジオ」→「HBCラジオ」)
- Listening with the screen off is more reliable and no longer stops when power saving cuts the network
- New update notice: the app will tell you when a new version is available
- Web app: pull-to-refresh is disabled, so scrolling back up or closing the player no longer reloads the page

### Downloads

- Android: `Radikall-release-1.0.1.apk`, installs over 1.0.0 and keeps your settings
- Windows: `Radikall-Setup-1.0.1.exe` (install VLC media player first)
- iOS / macOS: open https://radikall-web.baudmusic.workers.dev in Safari

## 日本語

数字は 1.0.0 から 1.0.1 へ少し進んだだけですが、UI から通信まわりまで作り直した大型アップデートです。

- 全国の放送局一覧と横断検索：エリアを切り替えなくても、どの局もワンタップで聴けます

- 画面オフでの長時間再生が安定し、省電力による通信切断で止まらなくなりました
- アップデート通知を追加：新しいバージョンが出るとアプリ内でお知らせします

## 한국어

숫자는 1.0.0에서 1.0.1로 조금 바뀌었을 뿐이지만, UI부터 네트워크 계층까지 거의 전부 새로 만든 큰 업데이트입니다.

- 전국 방송국 목록과 통합 검색: 지역을 바꾸지 않아도 어떤 방송국이든 한 번에 재생
- 방송국 카드에 방송 중인 프로그램 이름, 커버, 진행자 표시
- 일본 전통색으로 라이트/다크 테마를 새로 디자인
- Android에서 재생을 멈추고 시간이 지난 뒤 다시 재생하면 앱이 종료되던 문제 수정
- 네트워크가 끊겨도 자동으로 다시 연결해 복구 후 몇 초 안에 재생 재개

### 기타 개선

- 보고 있는 지역을 바꿔도 재생 중인 방송국이 끊기지 않습니다
- 재생 화면에 방송국의 청취 가능 지역을 표시하며, 탭하면 해당 지역으로 이동합니다
- 방송국·프로그램 이름의 전각 영문과 숫자를 반각으로 표시 (예: 「ＨＢＣラジオ」→「HBCラジオ」)
- 화면을 끈 채 오래 들어도 안정적이며, 절전으로 네트워크가 끊겨 멈추는 일이 없어졌습니다
- 업데이트 알림 추가: 새 버전이 나오면 앱에서 알려 줍니다
- 웹 버전: 당겨서 새로고침을 비활성화해 목록을 되돌리거나 재생 화면을 닫을 때의 오작동을 막았습니다
